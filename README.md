# Williams Portfolio

Personal portfolio of **Williams** — Full-Stack Software Developer & UX/UI Designer.

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and React Router.

## Sections

- **Home** — Introduction and main navigation
- **Product Studio** — Product and UX/UI focused work
- **Case Studies** — Selected project write-ups
- **Engineering Lab** — Full-stack projects and technical case studies
- **About / Skills / Work / Resume / Contact**

## Run locally

```bash
npm install
npm run dev
```
